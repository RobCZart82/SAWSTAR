# Presets

FactoryPresets.cpp embeds 24 complete parameter snapshots with stable keys,
learning descriptions and short searchable tags. Seven dry Templates provide
starting points; 17 finished sounds cover Lead, Pad, Pluck, Bass, Keys and Arp.

Library.h combines factory and user sounds, category/tag search and favorites.
UserPresets.cpp handles individual .sawstar files, atomic saves and recovery.
Factory presets require no companion bank. See docs/FACTORY_LIBRARY.md and
docs/USER_PRESETS.md for the behavior and validation limits.
