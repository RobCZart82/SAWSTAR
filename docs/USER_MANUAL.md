- [English PDF](manuals/SAWSTAR-User-Manual-EN.pdf)
- [Magyar PDF](manuals/SAWSTAR-User-Manual-HU.pdf)

The guides on this branch describe the prepared SAWSTAR 1.2.1 stable build,
30 embedded presets, sound design, performance, modulation, effects and user
preset operations. Chapter 15 covers Premium filters, 32-sample latency,
Classic project migration, reported 1.2.1 RC host feedback, the unresolved K1
numerical issue and block-based parameter automation. Screenshots show
SAWSTAR 1.0.3, capture build 8040390; their preset count includes user entries.
The latest published release remains 1.2.0 until separate publication.
See the [release checklist](RELEASE_1.2.1_CHECKLIST.md) for current readiness.

See [Installation](INSTALLATION.md) for the macOS per-package approval steps.
The GUI footer reports DSP CPU (not total OS CPU); its displayed value updates
about every 250 ms. The scope holds a frame about 90 ms. Neither changes audio.
